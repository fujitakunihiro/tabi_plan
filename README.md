# tabi. — 旅のスケジューラー

旅行の条件からChatGPTへの依頼文を作り、回答JSONを旅程として取り込むWebアプリです。アプリからGPT APIを呼び出す機能は無効にしました。APIキーは不要で、既存の環境変数にキーが残っていても使用しません。

## Dockerで起動

Docker Desktopを起動し、初回は `.env.example` を `.env` にコピーします（PowerShellでは `Copy-Item .env.example .env`）。既存の `.env` はそのまま利用できます。

```sh
docker compose -p tabi up --build -d
```

ブラウザーで http://localhost:8082/ を開きます。ポートは `.env` の `PORT` で設定します。旅程はDockerの名前付きボリューム `tabi_tabi-data` のSQLiteに保存され、コンテナの再作成後も残ります。

## ChatGPTで旅程を作る

1. 出発地・行き先・日程・ペース・好み・移動手段を設定します。
2. 「ChatGPTへの依頼文を作る」→「依頼文をコピー」を押します。
3. 「ChatGPTを開く」から依頼文を貼り、旅程を相談します。
4. 回答のjsonコードブロックをコピーし、アプリの「ChatGPTの回答JSON」に貼ります。
5. 「JSONを確認する」で行き先・日付・全日程を確認し、「この旅程を取り込む」を押します。

ChatGPTへの送信は利用者が手動で行います。ChatGPTの利用条件・利用上限は利用中のアカウントに従います。HTTPのVPN接続などでクリップボードが使えない場合は依頼文を選択するので、Ctrl+Cや長押しでコピーしてください。

JSONの形式は依頼文に含まれます。version:1、destination、startDate/endDate（YYYY-MM-DD）、daysを使用します。daysには日付順に全日分のdate、summary、eventsを入れます。予定はtime（HH:mm）、name、durationMinutes（整数5〜1440）、placeを使用し、origin、journeyRole（outbound/return/local）、timeLocked、officialUrlも指定できます。1〜21日、1日21予定以内に対応します。各日のfoodRecommendationsには最大3候補のname、place、specialty、nearbyTo、reason、urlを入れられます。

不正なJSON・実在しない日付・日数違い・不正な時刻・危険なURLは取り込みを止めます。時間の重なり・場所未設定・翌日への延長は注意として表示します。プレビュー中は現在の旅程を変更せず、取り込み時は現在の旅程を「保存した旅」に残し、新しいIDで取り込みます。保存に失敗した場合はエラーを表示します。取り込むJSONを書き換えた場合は、もう一度確認が必要です。

行き先が未定なら「行き先が未定なら、日程から探す」から相談用の依頼文を作れます。「ChatGPTに相談し直す」は現在の旅程も依頼文に含めます。

## 旅程の編集と地図

予定の追加・編集・削除、↑/↓の並べ替え、カードの「日程へ移動」、パソコンで日付タブへのドラッグに対応します。予約時刻は「時刻固定」で保持します。日程追加は空の日を追加し、帰路を新しい最終日へ移します。ChatGPTが提案する食事や店は、その日の予定カードとして確認できます。取り込んだサイトはアプリでは真偽を確認していないため「未検証」と表示します。

各日の「一日の動き」からGoogleマップを開き、ピンと予定順の経路を確認できます。Google Maps URLsを使い、Google APIキーは不要です。スマホの上限に合わせてルートを分割します。電車・バスで3地点以上の場合は全体図を道路ルートで表示し、区間別の電車・バス経路リンクを用意しています。

移動時間はOpenStreetMap Nominatimの地点とOSRMの道路経路による概算です。徒歩・電車・バスは距離から推定し、時刻表・渋滞は参照しません。場所不明の区間は未確認と表示します。GPT APIへのフォールバックはありません。地点検索はキャッシュし毎秒1回以内に制限しています。営業時間・休業日・予約・実際の交通は出発前に確認してください。

下書きと保存した旅の編集はDBへ自動保存します。保存失敗時は再試行できます。「保存した旅」で削除した旅程は「削除した旅」から復元できます。節約予算は人数・宿泊・食事・現地交通・入場料・往復交通費から概算し、旅程と一緒に保存します。

外出先ではDockerを動かすPCのVPNアドレスとポートで開きます（例：`http://100.x.x.x:8082/`）。同じサーバーのSQLiteを共有します。
